# -Enterprise-Feedback-Intelligence-UiPath-Gemini-AI-Pipeline
**Automated Customer Sentiment Analysis & Resolution Workflow**

## 🚀 The Business Problem
Manual processing of customer feedback is a major bottleneck for scaling businesses. This project solves the "unstructured data" problem by automating the scraping, analysis, and response drafting for customer reviews and support tickets.

## 🛠️ Technical Architecture & Stack
*   **RPA Orchestration**: **UiPath Studio** (managing web scraping and system data flows).
*   **AI Intelligence**: **Google Gemini (LLM)** for deep contextual sentiment analysis.
*   **Communication**: **Gmail API** for automated response drafting.
*   **Reporting**: **Google Sheets** for real-time intelligence dashboards.

## 🧠 Core Logic & Engineering
*   **Sentiment Scoring**: Granular scoring of customer feedback to identify at-risk accounts.
*   **Automated Response Generation**: Context-aware drafting based on sentiment and category.
*   **Resilient Error Handling**: Implemented custom try-catch blocks in UiPath to ensure 100% reliability.
